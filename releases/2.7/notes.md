- «Программы» → «Через Homebrew»: **KeepingYouAwake** — экран не гаснет и Mac не засыпает, пока включено. Один щелчок
  по значку-чашке в строке меню включает и выключает, в его меню — запуск при входе в систему. Открытый проект
  (github.com/newmarcel/KeepingYouAwake, MIT), сборка для Apple Silicon; ставится `brew install --cask keepingyouawake`.
