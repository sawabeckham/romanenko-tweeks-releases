# Romanenko Tweeks — установщики

Готовые сборки **Romanenko Tweeks** для Mac с Apple Silicon: твики macOS и программы Романенко (WebApp Maker,
Make Executable, MetalSharp-Wine ARM Creator) внутри. Скачать — в [Releases](../../releases/latest):

- `Romanenko-Tweeks-X.Y.pkg` — установщик: ставит программу в «Программы → RomanenkoApp». Он не подписан
  сертификатом разработчика: первый раз откройте его правой кнопкой → «Открыть».
- `Romanenko-Tweeks-X.Y.zip` — сама программа; отсюда Твики обновляются сами («Доступна версия…» в окне).

Сюда сборки кладёт GitHub Actions закрытого репозитория с исходниками; этот репозиторий только раздаёт их.
