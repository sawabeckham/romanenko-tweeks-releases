# Romanenko Tweeks — готовые сборки

Одна программа для Mac с Apple Silicon: твики macOS, создание веб-приложений и Windows-обёрток.
Скачать готовую версию — в [Releases](../../releases/latest).

- `Romanenko-Tweeks-X.Y.Z.pkg` — установщик в «Программы → RomanenkoApp».
- `Romanenko-Tweeks.pkg` — постоянное имя установщика последнего выпуска.
- `Romanenko-Tweeks-X.Y.Z.zip` — приложение для встроенного обновления.
- `SHA256SUMS` — контрольные суммы файлов соответствующего выпуска.

Собственные исходники Romanenko Tweeks хранятся в приватном репозитории и здесь не публикуются.
02.11.2026 ранее размещённые полные архивы исходников Твиков удалены из публичных вложений по решению владельца.
Установщики и архивы готовых приложений сохранены.

Отдельные исходники Wine и других сторонних компонентов, изменения к ним, лицензии и сведения об авторах
сохраняются в соответствующих релизах. Они не являются полным исходным кодом Romanenko Tweeks.

Этот репозиторий служит для распространения готовых сборок и сопроводительных лицензионных материалов;
выпуск выполняется из приватного проекта на Mac.
